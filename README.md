# Vocaloid PV Director

A Codex skill for directing story-led Vocaloid, UTAU, J-pop, and kinetic-typography lyric PVs. It focuses on character fidelity, concrete visual storytelling, non-slideshow motion, lyric timing, instrumental design, iterative visual QA, and safe project versioning.

## Install

Copy the `vocaloid-pv-director` folder into your Codex skills directory, then restart or refresh Codex.

## Use

Invoke it with `$vocaloid-pv-director`, or ask Codex to create, revise, critique, or render a Vocaloid-style lyric PV.

The skill contains workflow guidance only. It does not bundle songs, official artwork, generated user assets, or third-party rendering code.
